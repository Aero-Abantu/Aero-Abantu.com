# AeroAbantu Repository

This repository contains the source code for the **AeroAbantu** application.

## Overview

**AeroAbantu** is an AI Emergency Response Alert App built with React Native and Expo. It provides instant emergency assistance through AI-driven voice commands ("SOS" or "Help") and manual SOS triggers.

## Project Structure

- **[AeroAbantu](./AeroAbantu/)**: Contains the React Native / Expo mobile application code and documentation.

## Getting Started

To get started with the project, including installation, configuration, and running the app, please refer to the [AeroAbantu Project README](./AeroAbantu/README.md).
